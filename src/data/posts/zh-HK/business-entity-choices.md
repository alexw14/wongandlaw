選擇正確的法律架構是任何企業主最重要的早期決策之一。您選擇的實體類型決定了企業的稅務處理方式、您能獲得多少個人責任保護，以及日後引入投資者或合夥人的難易程度。本文比較了美國企業最常見的三種選擇：有限責任公司（LLC）、S型企業和C型企業。

## 有限責任公司（LLC）

LLC是中小型企業最靈活、最常選擇的架構。主要特點包括：

- **穿透課稅**：利潤和虧損直接流向成員的個人稅務申報，避免了C型企業的"雙重徵稅"問題
- **有限責任**：成員通常不對企業債務或訴訟承擔個人責任
- **靈活管理**：可由成員管理或經理管理，經營協議條款基本上可自由訂製
- **最低形式要求**：無需董事會、年度會議或複雜的記錄保存

LLC非常適合房地產持有、專業事務所、諮詢公司和家族企業。外國國民可以持有LLC的成員權益，這使其成為進入美國市場的國際企業家的熱門選擇。

## S型企業

S型企業是一種穿透型實體，可避免雙重徵稅，同時相對LLC提供一個重要的稅務優勢：**自僱稅節省**。在企業工作的所有者可以將收入分為"合理薪酬"（需繳納工資稅）和分紅（不需繳納自僱稅）。

然而，S型企業有嚴格的資格要求：

- 最多**100名股東**
- 股東必須是**美國公民或永久居民** — 外國國民不能持有S型企業股票
- 只允許**一類股票**
- 某些實體類型（其他企業、LLC、合夥企業）不能成為股東

公民身份限制對非居民外籍投資者和國際創始人是一個關鍵限制。

## C型企業

當您計劃尋求風險投資、發行多類股票或最終尋求IPO時，C型企業是首選架構。主要特點包括：

- **無限股東**且無公民身份限制 — 外國國民和實體可自由投資
- **多類股票**（普通股、優先股等）適合複雜的股權安排
- **附加福利**：某些員工福利可在公司層面扣除
- **留存收益**：利潤可按企業稅率（目前為21%）留在公司，而不必立即流向股東

主要缺點是**雙重徵稅**：公司對利潤繳納所得稅，股東再對收到的股息繳稅。對於將所有利潤再投資的早期初創企業來說，這通常不是實際問題。

## 哪種架構適合您？

| 因素 | LLC | S型企業 | C型企業 |
|---|---|---|---|
| 穿透課稅 | ✓ | ✓ | ✗ |
| 允許外國所有權 | ✓ | ✗ | ✓ |
| 自僱稅節省 | 有限 | ✓ | 不適用 |
| 適合VC/投資者 | 有限 | 有限 | ✓ |
| 形式要求 | 低 | 中等 | 高 |

對於在美國建立企業的中國或香港企業家來說，**LLC**或**C型企業**幾乎總是正確的選擇。LLC適合所有者將積極管理公司並偏好簡單性的運營企業。C型企業適合以外部投資、股票期權計劃或長期退出策略為優先考慮的情況。
